# Assignment 2-3 Part B – IDE Features Reflection

## Introduction

For this assignment, I opted to use my own personal IDE, PyCharm. Before taking this class, I had already gained a solid foundation in Python, so I have had experience choosing an IDE. One feature I chose about PyCharm is it's tab structure. Another feature I chose is the option to change the color scheme. I find that finding the right color scheme can help see the code easier, like the text color for different types of Python code, or even just being easier on the eyes when coding for long periods of time. The last feature I chose is the file viewer on the left hand side. I find it easy to navigate and view my files at a glance.

## Feature 1 – Tab Structure

The first feature I chose is PyCharm's tab structure at the top of the window. This helped increase my workflow because I could easily switch between each file as needed. For example, when completing the SDW, I could switch to the requirements with ease. This feature would be excellent for beginners because it provides the necessary files at the click of a mouse to be able to view and modify files quickly.

## Feature 2 – Color Scheme

The second feature I chose is PyCharm's option to change the color scheme. This feature changes the background color, text color, and code highlighting. It has a lot of benefits while coding, like if I have an unused variable, some color schemes will gray out the variable name. For beginners, this can be very useful because if you find a color scheme you like, then you can visually see your code and potentially any mistakes you made. I chose a high contrast color scheme. This allowed me to see variables, constants, and the main function easier.

## Feature 3 – File Viewer

The third feature I chose is PyCharm's file viewer. It is a tab on the left side of the screen that displays all files and folders. It can be toggled by clicking the file icon in the top left hand corner of the screen. This helped me enhance my experience greatly due to its ease of use. During this project/assignment, there were many files to keep track of. The file viewer made it visually simple to find the files and folders that were being referred to in each part.

## Conclusion

In this assignment, I saw how a mixture of these three features made my workflow smooth and simple. They helped my confidence because I have never worked on a project this big before, so the tabs, color cheme, and file viewer made this project a lot less daunting than I had originally expected
